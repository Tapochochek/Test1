# ОренКод — стартовый прототип цифровой платформы ФСП

Короче ебаный бот в максе создается только если есть лицуха у организации вьебал бота в телеге, хуй знает вроде работает там чето можно уведы привязать по ссылке это на бота @FSP56OrenburgBot

Первый технический срез для хакатона: интерфейс региональной платформы, API на Go, PostgreSQL, Docker Compose и интеграция с Telegram-ботом для справки о соревнованиях/рейтинге и персональных уведомлений.

> В этой версии реализованы регистрация, вход, сессии и серверная проверка активной роли для защищённых API-маршрутов. Это всё ещё прототип: аудит и часть спортивных регламентов требуют дополнительной проверки перед эксплуатацией с реальными персональными данными.

## Запуск

Нужен Docker с Compose v2.

```bash
docker compose up --build
```

После запуска:

- Веб-интерфейс: <http://localhost:8080>
- API: <http://localhost:8081/api/health>
- PostgreSQL доступен только внутри compose-сети на сервисе `db`.

При первом запуске API создаёт таблицы и заполняет базу демонстрационными данными. Имена, организации и результаты вымышлены. Состояние базы хранится в volume `postgres_data`. Повторный запуск не дублирует демо-записи.

### Локальная разработка API

Нужны Go 1.23+ и PostgreSQL. Из каталога `backend`:

```bash
cd backend
# PowerShell: $env:DATABASE_URL="postgres://orenkod:orenkod_local@localhost:5432/orenkod?sslmode=disable"
# bash: export DATABASE_URL=postgres://orenkod:orenkod_local@localhost:5432/orenkod?sslmode=disable
go run ./cmd/api
```

Тесты и проверка сборки:

```bash
cd backend
go test ./...
go vet ./...
go build ./...
```

Сбросить демонстрационную базу:

```bash
docker compose down -v
docker compose up --build
```

## Что уже есть

- Главная панель со сводными показателями, ближайшими соревнованиями, рейтингом и уведомлениями.
- Разделы «Соревнования», «Участники», «Рейтинг», «Сборная», «Документы» и «Уведомления».
- Регистрация и вход по email/паролю, bcrypt-хеширование пароля, 12-часовая серверная сессия и выход.
- Роли Федерация, Тренер, Спортсмен и Судья; переключение доступно только между ролями, назначенными конкретному аккаунту. Самостоятельно зарегистрироваться как Федерация нельзя.
- Профили тренера/судьи и профиль спортсмена с проверкой дисциплины, возраста, возрастной группы и согласием законного представителя для несовершеннолетних.
- Федерация может создавать и публиковать соревнования, просматривать заявки и принимать решения; спортсмен может подать заявку; назначенный судья или Федерация могут сохранять результаты.
- Создание соревнования через интерфейс и сохранение в PostgreSQL.
- REST API для соревнований, реестра спортсменов, рейтинга, сборной и уведомлений.
- Docker Compose, Nginx reverse proxy, health endpoint и базовые проверки входных данных.
- Telegram-бот (long polling): команды `/start`, `/events`, `/rating`, `/help`, `/link КОД`; одноразовая привязка аккаунта и персональные уведомления о решениях по заявкам/разрядам/судейским категориям и публикации результатов. Реальная доставка требует токена Telegram; long polling работает локально без публичного HTTPS webhook.

## API

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/api/health` | Проверка сервиса |
| `POST` | `/api/auth/register` | Регистрация спортсмена, тренера или судьи; возвращает сессию |
| `POST` | `/api/auth/login` | Вход и выдача токена сессии |
| `GET` | `/api/auth/me` | Текущий пользователь и доступные роли; нужен Bearer-токен |
| `POST` | `/api/auth/switch-role` | Смена активной роли на одну из назначенных аккаунту |
| `POST` | `/api/auth/logout` | Завершение сессии |
| `GET` | `/api/dashboard` | Сводка для главной страницы; нужен Bearer-токен |
| `GET` | `/api/competitions` | Список соревнований |
| `POST` | `/api/competitions` | Создание черновика соревнования |
| `GET` | `/api/athletes` | Реестр спортсменов |
| `GET` | `/api/rating` | Рейтинг по набранным очкам |
| `GET` | `/api/team` | Текущий демонстрационный состав сборной |
| `GET` | `/api/notifications` | Демонстрационные уведомления |
| `GET` | `/api/integrations/telegram/status` | Статус конфигурации Telegram |
| `GET` | `/api/integrations/telegram/link-status` | Проверить привязку текущего аккаунта; Bearer-токен |
| `POST` | `/api/integrations/telegram/link-code` | Создать одноразовый код привязки (10 минут); Bearer-токен |
| `DELETE` | `/api/integrations/telegram/link` | Отключить Telegram от текущего аккаунта; Bearer-токен |

`POST /api/competitions` принимает JSON:

```json
{
  "title": "Кубок Оренбургской области",
  "discipline": "Программирование",
  "competition_type": "Региональный",
  "age_group": "Юниоры",
  "starts_at": "2026-11-21T10:00:00+05:00",
  "location": "Оренбург"
}
```

В этой версии заявки хранятся в таблице `applications`. Для защищённых API отправляйте заголовок `Authorization: Bearer <token>`. Роль `federation` назначается администрацией, а не через публичную регистрацию.

## ФСП ID (Д1) — OpenID Connect провайдер

Платформа выступает провайдером OIDC: authorization code + **PKCE (S256)**, подписанный `id_token` (RS256).

| Что | Адрес |
|---|---|
| Discovery | `/.well-known/openid-configuration` |
| Authorize (страница входа и согласия) | `/oidc/authorize` |
| Token | `POST /oidc/token` |
| Userinfo | `GET /oidc/userinfo` (Bearer) |
| JWKS | `/oidc/jwks.json` |
| Регистрация клиентов (роль «Федерация») | `/oidc/admin`, API `GET/POST/DELETE /api/oidc/clients` |
| Тестовое приложение | `/oidc/demo` (клиент `fsp-demo-client`) |

Scope: `openid profile email roles sport` (`sport` = fsp_id, дисциплины, разряд). Проверка: откройте http://localhost:8080/oidc/demo → «Войти через ФСП ID» → войдите → «Разрешить» → на странице появятся `id_token` и `userinfo`.
Для приложений-партнёров: публичный клиент (только PKCE) или конфиденциальный (`client_secret`, выдаётся один раз). Redirect URI — только https или localhost, точное совпадение.

## Почта (коды входа) на хостинге
Многие хостинги (в т.ч. бесплатный Render) блокируют исходящий SMTP, поэтому письма с кодами не доходят. Надёжный вариант — HTTP API Brevo: создайте бесплатный аккаунт на brevo.com, подтвердите отправителя (можно Gmail), получите API-ключ и задайте переменные `BREVO_API_KEY` и `SMTP_FROM` (адрес подтверждённого отправителя). SMTP остаётся запасным путём (порты 587 и 465, по две попытки). При неудаче отправки повторить запрос можно сразу. Без настроек код печатается в логе api.

## ФСП ID и интеграции
Демо-клиент ФСП ID (`/oidc/demo`) работает на любом адресе платформы (localhost, Render). Страница интеграций требует активную роль «Федерация»: если активна другая роль, на странице появляется кнопка переключения.
