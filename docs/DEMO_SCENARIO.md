# Сценарий демонстрации прототипа

Ожидаемая продолжительность: 3–5 минут.

## 1. Главная панель

Показать ключевые сущности платформы: спортсмены, соревнования, заявки, судьи. Уточнить, что числа и пользовательские данные искусственные и нужны для демонстрации интерфейса.

## 2. Создать соревнование

1. Нажать «Создать соревнование».
2. Ввести название, дисциплину, тип, возрастную группу, дату и место.
3. Сохранить черновик.
4. Открыть «Соревнования» и найти новое событие.

Это сквозной работающий сценарий в текущем срезе: React → Go API → PostgreSQL → повторная загрузка данных.

## 3. Реестр и рейтинг

1. Открыть «Реестр участников», поискать по ФИО или организации.
2. Открыть «Рейтинг», выбрать дисциплину, показать порядок спортсменов.
3. Перейти в «Сборная области» и пояснить, что сейчас там показан топ-5 как пример интерфейса, а не официальный критерий отбора.

## 4. MAX-интеграция

Показать карточку «Оповещения в MAX». Объяснить планируемые сценарии: `/events`, `/rating`, напоминания о сроках и уведомления о создании соревнования. Для живого теста необходимы одобренный бот, токен, webhook secret, публичный HTTPS-домен и подписка MAX на события.

## Пример API-запроса

```bash
curl -X POST http://localhost:8081/api/competitions \
  -H 'Content-Type: application/json' \
  -d '{"title":"Тестовый кубок Оренбуржья","discipline":"Программирование","competition_type":"Региональный","age_group":"Юниоры","starts_at":"2026-11-21T10:00:00+05:00","location":"Оренбург"}'
```

Посмотреть данные API можно по адресам `http://localhost:8081/api/dashboard`, `http://localhost:8081/api/rating` и `http://localhost:8081/api/integrations/max/status`.

## Честное разграничение

Реестр и рейтинг в прототипе доступны для чтения. Создание соревнования — единственный полноценный редактирующий бизнес-сценарий сейчас. Заявки, роли с настоящей проверкой прав, результаты, протоколы, присвоение разрядов, экспорт и официальные правила рейтинга — следующий этап.
